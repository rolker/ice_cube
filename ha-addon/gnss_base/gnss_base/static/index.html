Base setup

Each step shows the exact command first. Steps that change the receiver ask you to confirm.

  1. Read the firmware version. Sends $PQTMVERNO*58 at once (read-only).
  2. Check the receiver profile with read-only queries; then apply the differences if you choose.
  3. Switch to base mode: PQTMCFGRCVRMODE,W,2, save, then restart with PQTMSRR. The receiver restarts and stops sending NMEA.
  4. Start a survey-in of fixes, with no accuracy limit, save, then restart with PQTMSRR: this firmware starts a survey-in only after a restart.
  5. Set a fixed base position, save, then restart with PQTMSRR so it takes effect. The survey-in mean is used only once the survey-in has finished (Valid=2).
