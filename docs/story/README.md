# Story

The narrative half of the repo, in the author's voice. Each chapter file is currently an
**outline, not written**: bulleted facts and prompts to write from, with each fact marked
by where it comes from:

- `[own words]`: said or written by the author (chat or draft), usable as is.
- `[reconstructed]`: pieced together from analysis notes, logs and the journal; check
  before writing it as memory.

Chapters, in order:

1. `2026-01-how-it-started.md`: snow, a week of cold, a rink with no plan, and a phone.
2. `2026-02-ice-cube.md`: surveying the ice, the CUBE half-joke, and the spoof paper.
3. `2026-10-surveying-the-yard.md`: planning this season's rink, and what the GPS said.
4. `2026-11-base-station.md`: building a base station, and finding out where it is.

Dates in filenames are the month the chapter is about, not when it was written. Numbers
are in `../log.md` and `../howto/`; the chapters should point there rather than repeat them.
